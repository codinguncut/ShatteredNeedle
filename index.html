The evidence is there. The answer is not.

Shattered Needle tests whether an AI agent can turn hundreds of scattered, ordinary documents into a durable web of knowledge, then solve held-out cases after the source material has been taken away.

The question

Can a model prepare before it knows what will be asked?

Most retrieval tests hand the system a question first. Shattered Needle reverses the order. The agent must organize the corpus in anticipation of unknown future questions, under compression, without being told which facts will matter.

Retrieval finds a document. This benchmark asks whether an agent can reconstruct the latent proposition that no document states alone.
Target construct: anticipatory knowledge organization under compression

Every clue is mundane in isolation: a registry entry, a role description, an observed act, an inventory record. The challenge is to resolve aliases and relationships, join evidence across files, preserve provenance, and identify the one suspect satisfying six independently scattered criteria.

The benchmark is representation-agnostic. A model may build Markdown, tables, a graph, a database, or something else entirely. Its internal structure is not scored. Only what a fresh same-model session can recover from that frozen artifact counts.

Protocol / same model, separate sessions

A hard air gap between reading and answering.

01

WEAVE

Build the fabric

The model receives the 877-document corpus and an ingest task. It reads, cross-links, compresses, and writes a persistent knowledge base to ./fabric.

  • No held-out questions
  • No prescribed memory format
  • Every retained claim should carry its source filename
corpus removed
02

QUERY

Recover from memory

A fresh session of the same model receives only the frozen fabric and 307 questions. The corpus is physically absent. Answers are written to a structured file.

  • No shared chat memory
  • No source-document access
  • Entity and provenance answers graded offline

The only communication channel is the filesystem artifact. This isolates build-and-recover capability from query-time retrieval over the original corpus.

Data generation

A compiler designed to be decompiled.

The private generator starts with target propositions and lowers them through a hidden derivation graph. Only the leaves become natural-language documents. Forward derivation verifies the answer; the agent must run the process backward.

01 / World

Mint a fictional state

Fictional people and organizations prevent real-world recall. Relations and document genres remain realistic enough to demand ordinary reading.

02 / Proof

Compile the answer

Function-free Horn operators create a hidden proof from aliases, coreference, joins, set intersection, and rule application.

03 / Projection

Expose only leaves

Derived facts and case labels are withheld. Evidence leaves are dispersed across documents and mixed with certified-inert distractors.

04 / Realization

Write irregular prose

Leaves become memos, logs, correspondence, registries, statements, and excerpts with varied filenames and indirect references.

05 / Certification

Guard uniqueness

The logic engine verifies solvability and provenance while ensuring distractors do not license a second valid derivation.

06 / Freeze

Hash the instance

All 877 corpus files are listed by SHA-256 in the manifest. Answers are held separately for deterministic, non-LLM grading.

What this run says

Facts are not the same thing as a conclusion.

This is one frozen instance, not a universal model ranking. Its value is diagnostic: it separates evidence capture, identity resolution, provenance fidelity, and final confluence.

Finding 01

High flat accuracy can hide synthesis failure.

Sol recovered 293 of 307 answers, including nearly every resolution and provenance item, but abstained on all 12 culprit conclusions. The weighted score exposes that gap: 0.4471.

Finding 02

The benchmark has not reached its ceiling.

Two portable runs and historical Claude Opus solved v1 perfectly. The instance measures meaningful separation below the frontier, but a larger, harder corpus is required to discriminate among top systems.

Finding 03

Long-horizon reliability is part of the result.

Provider timeouts, unsafe parallel writers, permission prompts, compaction loops, and orphaned workers prevented several runs from producing a score. The benchmark exercises an agentic process, not just one completion.

DeepSeek’s operator-assisted diagnostic

DeepSeek did finish WEAVE after operator repair and deterministic consolidation, but its autonomous same-model QUERY did not finish. A separate corpus-free diagnostic used six operator-managed workers to query the preserved fabric and scored 289/307 flat, 0.8899 weighted, including 10/12 culprit answers. It demonstrates information retained by the fabric, not autonomous DeepSeek end-to-end performance.

Why failed runs are reported

A benchmark of persistent agentic work should not silently condition on successful execution. Failures reveal resumability, process hygiene, provider reliability, and whether useful state survives interruption. They remain outside scored comparisons but inside the evidence record.

Time, tokens, and cost

Measured where possible. Estimated with dated rates.

OpenRouter costs below are sums of per-message billed values captured by OpenCode across parent and subagent sessions. For plan-based runs, the API-equivalent figures apply public standard tariffs to measured usage; they are not charges paid during the run.

Estimation rule

Using standard public rates retrieved on 17 August 2026:

(uncached input × input rate) + (cache writes × write rate) + (cache reads × read rate) + ((output + reasoning) × output rate)

Each request remained within the applicable standard pricing tier. Where a provider reports reasoning separately, it is added to output and charged at the output rate. Anthropic includes extended-thinking tokens in output_tokens, so Claude reasoning is already included; those estimates also include measured five-minute cache writes and cache hits. Prices and provider semantics change, so these are approximations.

Read with care

What v1 does not establish.

  1. One instance is not a population. Results can support diagnosis and engineering decisions, not broad statistical claims about model families.
  2. The frontier can fit the raw corpus. At roughly 305k tokens, v1 is below some 500k-token context windows. External memory pressure also includes reasoning state, but a future instance should exceed frontier windows.
  3. Harness conditions differ at the margins. Context windows, reasoning variants, subscription plans, provider routing, resumes, and historical prompts are disclosed rather than normalized away.
  4. Perfect scores imply a ceiling. The next useful iteration needs more real cases and deeper compounded irregularity while preserving deterministic certification.

The intended measurement

Not “can it search?” but “what did it build before search was possible?”

Shattered Needle is a single hard point in the larger FabricBench program: measuring whether agents can ingest, cross-link, and synthesize durable knowledge under realistic obfuscation.

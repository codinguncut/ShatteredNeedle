Shattered Needle

Shattered Needle benchmarks anticipatory knowledge organization under compression: an agent ingests documents across several isolated sessions into a persistent fabric, then answers previously unseen questions using only that fabric.

A needle-in-a-haystack task turned inside out. The answer is not a span to locate — the needle is shattered into fragments scattered across the corpus, and success requires reassembling those fragments into durable, reusable knowledge.

Benchmark

What it measures

Shattered Needle evaluates an agent's ability to construct and maintain useful knowledge over a long-running investigation. The agent processes a large corpus over an extended trajectory, using a persistent knowledge base as external memory under a bounded working context. After the investigation, it must use the knowledge base it constructed to answer held-out questions that were not available while it was processing the corpus.

Grading is mechanical and representation-agnostic: the agent is free to organize its knowledge base however it likes, and is scored on what that knowledge base recovers, never on its format.

The wider research suite applies the same protocol to investigative, OCR-noised procedural, and chronology-heavy narrative corpora. This site keeps one top-level leaderboard rather than adding separate per-corpus rankings.

Run comparability

Measured rows use the same six-tranche harness, frozen corpus, task contract, and mechanical grader. Projected Claude rows are planning estimates, not official v3.3 results: Fable 5.1 and Opus 5 carry forward their measured v3 scores; Sonnet 5 carries forward its latest comparable v2 score.

Failed and interrupted runs

Interrupted v3.3 cells are excluded until they produce a completed, mechanically scored QUERY. Current resumable cells include K3, Qwen3.8 Max, Gemini 3.8 Flash, and GLM-5.3 Flash. Their partial work, cost, and time are not averaged into the leaderboard.

Pricing and token accounting

Actual OpenRouter and xAI values are reported bills. Estimated values apply the public standard token rates recorded by the benchmark to measured usage:

input + cache writes + cache reads + (output + separately reported reasoning)

Unmetered subscription runs have no actual billed amount. Their Cost value is a pay-per-token equivalent marked with an e suffix. Estimates are lower bounds when a provider applies a per-request long-context surcharge that aggregate token totals cannot reconstruct.

Sources: OpenAI, Anthropic, MiniMax, Z.AI, and OpenRouter.

Generation and certification

A private generator starts from target propositions, lowers them through a function-free Horn derivation graph, and realizes only the leaves as natural-language documents. The forward engine verifies solvability and uniqueness. Distractors are certified not to license an alternative derivation, and all corpus files are frozen by SHA-256 manifest.
